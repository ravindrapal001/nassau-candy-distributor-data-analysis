# Geographic Route Analysis — Power BI

## Project
Nassau Candy Distributor — Shipping Route Efficiency Analysis

## Objective
Explore geographic differences in sales, gross profit, units, orders, and cost using Power BI.

## Report Components
- Total Sales KPI
- Total Gross Profit KPI
- Sales by Region and State
- Geographic Group Summary
- Sales vs Gross Profit scatter chart
- Region slicer for interactive analysis

## Data Validation
All measures must be validated against the source dataset using consistent filters and aggregation definitions. Geographic mappings and model relationships must be checked before interpreting results.

## Limitations
Geographic sales and profitability analysis does not independently establish shipping-route efficiency. Route identifiers, distance, valid shipment dates, transit times, and business performance targets may be required for operational conclusions.
